# Object Show Sim ALPHA 2: Changelog (English)
* Most of the code was refactored
* The CLI system was reinvented, so it's easier to use and more aesthetically pleasing
* Added a language selector
* Added Spanish language
* The minimum of contestants changed from  `8` to `3` and the maximum changed from `50` to `64`
* You can now choose the number of finalists that a season has
* The gender of the contestants is now functional and affects simulation messages, including pronouns and suffixes in languages that use them
* Minor changes in the simulation messages

# Object Show Sim ALPHA2: Changelog (Español)
* Se refactorizó casi todo el código
* Se reinventó el sistema de CLI, para que sea más cómodo de utilizar y que se vea más estético
