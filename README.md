# Object Show Sim ALPHA 3 - Challenge Update
Text-based object show simulator coded in Ruby

## Changelog
ALPHA 3 changelog is in both English and Spanish, see here: [CHANGELOG](CHANGELOG.md)

## Description
This is a prototype CLI/Terminal, text-based object show simulator based on Ruby, it will remain built this way until it reaches its BETA stage, which is when the entire project will be redone as an HTML/CSS/JavaScript project. This simulator offers a simple, text-only demonstration of what it's supposed to be: You can create up to 64 contestants and have them compete in an object show, you can set attributes for your contestants, which will help determine their performance in various challenges. Eliminations and finales are still random as of now.

## Requirements
* Windows 7 or up / Any other operating system that can run the 32 bit version of Ruby 3.1.4
* Ruby 3.x installed (only if you're not using windows or want to experiment with the code yourself)

## Installation
* Go to the [ALPHA 3 release page](https://github.com/alejandroso31/object-show-sim/releases/tag/ALPHA2)
* Windows: Simply download `ObjectShowSim_ALPHA3_WindowsX32.zip` and extract it in its own folder wherever you wish.
* Other systems: Simply download `ObjectShowSim_ALPHA3_Source.zip` and extract it in its own directory wherever you wish.

## Execution
* Windows: Simply open `ObjectShowSim_ALPHA3.bat` and you're ready to go!
* Other systems: You may either open `main.rb` and allow it to be executed as a program in the terminal or open the installation directory on a terminal and type the following command: `ruby main.rb`, then, you're ready to go
