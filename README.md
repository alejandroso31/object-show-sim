# Object Show Sim ALPHA 2
Text-based object show simulator coded in Ruby

## Changelog
ALPHA 2 changelog is in both English and Spanish, see here: [CHANGELOG](CHANGELOG.md)

## Description
This is a prototype CLI/Terminal, text-based object show simulator based on Ruby, it will remain built this way until it reaches its BETA stage, which is when the entire project will be redone as an HTML/CSS/JavaScript project. This simulator offers an extremely simple and unpolished demonstration of what it's supposed to be: You can create up to 64 contestants and have them compete in an object show, as of now, this simulator has basic logic and its results are entirely random.

## Requirements
* Any Operating System that is able to run Ruby 3.x in the terminal (Windows, MacOS, Linux)
* Ruby 3.x installed (add to PATH if asked and if you're using Windows)

## Installation
Simply extract the .zip file anywhere you want.

## Execution
You may simply double click on the main.rb script (and choose to execute it in the terminal if asked) or you may open the folder in a terminal and type the following command: `ruby main.rb` if the first method fails.
